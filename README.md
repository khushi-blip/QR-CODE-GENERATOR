# UPI QR Code Generator 💳

This Python project generates UPI payment QR codes for PhonePe, Paytm, and Google Pay using a UPI ID input from the user.

## 🚀 Features
- Takes UPI ID as input
- Generates UPI payment links
- Creates QR codes for:
  - PhonePe
  - Paytm
  - Google Pay
- Displays and saves QR images

## 🛠️ Tech Stack
- Python
- qrcode (with PIL)

## 📦 Installation
pip install qrcode[pil]
How To Run
python main.py
enter upi id when asked

📸 Output
The program generates:

phonepay_qr.png

paytm_qr.png

googlepay_qr.png
